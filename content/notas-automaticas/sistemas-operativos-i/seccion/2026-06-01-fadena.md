## Conceptos clave
- **Shell**: Interfaz de línea de comandos que permite interactuar con el sistema operativo.
- **man**: Comando que muestra el manual de otros comandos.
- **pwd**: Muestra el directorio de trabajo actual.
- **ls**: Lista el contenido del directorio actual.
- **cd**: Cambia de directorio.
- **mkdir**: Crea un nuevo directorio.
- **rmdir**: Borra un directorio vacío.
- **cat**: Muestra el contenido de un archivo.
- **nano**: Editor de texto en la terminal.
- **rm**: Elimina archivos.
- **sudo**: Permite ejecutar comandos con privilegios de superusuario.
