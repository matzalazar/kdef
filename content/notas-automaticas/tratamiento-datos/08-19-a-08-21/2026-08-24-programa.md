**Conceptos clave**  
- **Dato, información y conocimiento**: elementos básicos del tratamiento de datos.  
- **Ciclo de vida del dato**: creación, almacenamiento, uso, archivado y eliminación.  
- **Sistema de Gestión de Bases de Datos (SGBD)**: software que permite definir, manipular y administrar bases de datos.  
- **Modelos de datos**: jerárquico, de red y relacional; conceptos de entidad, atributo, tupla y relación.  
- **Normalización**: proceso de organizar datos para reducir redundancia y anomalías (1FN, 2FN, 3FN, BCNF, etc.).  
- **SQL**: lenguaje de consulta estructurado (DDL, DML, DQL, DCL, TCL).  
- **Joins y subconsultas**: técnicas para combinar y filtrar información de múltiples tablas.  
- **Transacciones y propiedades ACID**: atomicidad, consistencia, aislamiento y durabilidad.  
- **Vistas, índices y procedimientos almacenados**: mecanismos para optimizar consultas y reutilizar lógica.  
- **Seguridad en bases de datos**: autenticación, autorización (RBAC), cifrado y auditoría.  
- **Concurrencia y recuperación**: control de bloqueo, timestamps, logs y puntos de control.  
- **Modelos de procesamiento**: cliente‑servidor, distribución de datos, two‑phase commit, propagación asincrónica.  
- **Formatos de intercambio**: CSV, XML, JSON, YAML y logs.  
- **Expresiones regulares (REGEX)**: patrones para búsqueda y validación de texto en contexto de ciberdefensa.  
- **Bases de datos NoSQL**: clasificación clave‑valor, documentales, columnares y de grafos; ejemplos Redis, MongoDB, Cassandra, Neo4j.  
- **Teorema CAP**: trade‑off entre consistencia, disponibilidad y tolerancia a particiones en sistemas distribuidos.  
- **Big Data y tecnologías distribuidas**: Hadoop, Spark, HDFS, MapReduce y características Volumen, Velocidad, Variedad, Veracidad, Valor.  
- **Bases de datos en la nube (DBaaS)**: servicios como Firebase, Amazon RDS y Azure SQL.
