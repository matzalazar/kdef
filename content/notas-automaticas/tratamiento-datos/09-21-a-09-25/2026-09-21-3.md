**Conceptos clave**  
- **SQL (Structured Query Language)**: lenguaje estándar para definición, manipulación y control de bases de datos relacionales.  
- **DDL (Data Definition Language)**: sentencias CREATE, ALTER, DROP para definir esquemas, tablas y restricciones.  
- **DML (Data Manipulation Language)**: sentencias INSERT, UPDATE, DELETE y SELECT para manipular y consultar datos.  
- **DCL (Data Control Language)**: sentencias GRANT y REVOKE para gestionar privilegios.  
- **TCL (Transaction Control Language)**: sentencias COMMIT, ROLLBACK y SAVEPOINT para controlar transacciones.  
- **Tipos de datos**: CHAR, VARCHAR, INTEGER, NUMERIC, DATE, TIME, etc.  
- **Restricciones de columna**: NOT NULL, NULL, UNIQUE, PRIMARY KEY, REFERENCES, CHECK.  
- **Restricciones de tabla**: UNIQUE, PRIMARY KEY, FOREIGN KEY, CHECK (a nivel de tabla).  
- **Cláusulas de consulta**: SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY, DISTINCT, JOIN (INNER, LEFT, RIGHT, FULL).  
- **Funciones de agregación**: COUNT, SUM, AVG, MIN, MAX.  
- **Operadores de comparación y lógicos**: =, <>, <, >, <=, >=, AND, OR, NOT, BETWEEN, IN, LIKE, IS NULL.  
- **Funciones de cadena y fecha**: UPPER, LOWER, CONCAT, SUBSTR, TRIM, EXTRACT, YEAR, MONTH, DAY, DATEDIFF, DATEADD, CURRENT_DATE.
