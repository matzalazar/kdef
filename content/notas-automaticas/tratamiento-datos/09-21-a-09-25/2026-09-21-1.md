# Resumen de "SQL Básico - Presentación"

## Conceptos clave
- **SQL**: Lenguaje estándar para definición, manipulación y control de bases de datos relacionales.  
- **DDL (Data Definition Language)**: Sentencias que definen el esquema (CREATE, ALTER, DROP).  
- **DML (Data Manipulation Language)**: Sentencias que manipulan los datos (INSERT, UPDATE, DELETE, SELECT).  
- **DCL (Data Control Language)**: Gestión de permisos y seguridad.  
- **TCL (Transaction Control Language)**: Control de transacciones.  
- **Restricciones de columna**: PRIMARY KEY, UNIQUE, REFERENCES (clave foránea), NOT NULL, CHECK.  
- **Restricciones de tabla**: idem a nivel de conjunto de columnas, con posibilidad de nombrarlas mediante CONSTRAINT.  
- **Acciones ON DELETE / ON UPDATE**: NO ACTION/RESTRICT, CASCADE, SET NULL, SET DEFAULT.  
- **Operadores de comparación y lógicos**: =, <>, <, >, <=, >=, AND, OR, NOT, con precedencia NOT → AND → OR.  
- **Operadores especiales**: BETWEEN, IN, LIKE (comodines % y _), IS NULL / IS NOT NULL.  
- **Funciones**: matemáticas (ABS, SQRT, POWER, etc.), de fecha (YEAR, MONTH, DAY, DATEDIFF, DATEADD, CURRENT_DATE), de cadena (CONCAT, UPPER/LOWER, LENGTH, REPLACE, SUBSTRING, TRIM, COALESCE).  
- **Funciones de agregación**: COUNT, SUM, MAX, MIN, AVG, con uso de DISTINCT y GROUP BY.  
- **Agrupamiento**: GROUP BY forma grupos; HAVING filtra grupos usando funciones de agregación.  
- **JOIN**: producto cartesiano (coma), JOIN explícito con ON, y variantes OUTER (LEFT, RIGHT, FULL).
