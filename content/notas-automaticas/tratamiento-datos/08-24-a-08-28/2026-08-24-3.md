# Modelos de datos y abstracción

**Título:** Modelos de datos y abstracción  
**Conceptos clave:**  
- Modelado de datos: proceso de crear una representación abstracta de los datos del mundo real para diseñar una base de datos.  
- Modelo jerárquico: estructura de árbol con un único padre por registro; eficaz para relaciones 1:N pero rígido y poco flexible para relaciones M:N.  
- Modelo de red: permite que un registro tenga múltiples padres mediante conjuntos (propietario‑miembro), superando la limitación jerárquica pero aumentando la complejidad.  
- Modelo relacional: organiza datos en tablas (relaciones) con columnas y filas; usa claves primarias y foráneas, SQL y normalización para reducir redundancia y garantizar integridad.  
- Modelo orientado a objetos (OO): representa datos como objetos que encapsulan atributos y métodos; facilita la integración con lenguajes OOP pero carece de estándares universales.  
- Modelos NoSQL: categoría diversa (clave‑valor, documentos, grafos, columnas) diseñada para grandes volúmenes de datos no estructurados o semiestructurados, alta escalabilidad horizontal y flexibilidad de esquema.  
- Arquitectura ANSI/SPARC: tres niveles de abstracción – externo (visión), conceptual (lógico) e interno (físico) – con mapeos entre ellos y conceptos de independencia física y lógica de los datos.  
- Independencia física de datos: capacidad de modificar el almacenamiento interno sin afectar el esquema conceptual ni las aplicaciones.  
- Independencia lógica de datos: capacidad de cambiar el esquema conceptual sin alterar las vistas externas ni las aplicaciones que no usan esos cambios.
