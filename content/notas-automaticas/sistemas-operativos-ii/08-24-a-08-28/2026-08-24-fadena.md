**FADENA SO II – S2‑A2**  
*Gestión de procesos en Linux Ubuntu desde la Terminal*

**Conceptos clave**  
- **Proceso**: instancia de un programa en ejecución.  
- **PID (Process ID)**: número único asignado por el SO a cada proceso.  
- **PPID (Parent Process ID)**: PID del proceso que creó al proceso actual.  
- **Usuario (User)**: propietario del proceso (usuario actual, root u otro).  
- **%CPU**: porcentaje de tiempo de CPU utilizado por un proceso.  
- **%MEM**: porcentaje de memoria RAM consumida por un proceso.  
- **STAT/S**: estado actual del proceso (ejecutándose, en espera, detenido, zombie, etc.).  
- **PRI/NI**: prioridad de ejecución; NI (nice value) ajusta dicha prioridad (valores de –20 a 19, siendo 0 el valor por defecto).  
- **Comandos de monitorización**: `ps`, `ps -e`, `ps -f`, `ps aux`, `top`.  
- **Comandos de control**: `kill` (SIGTERM por defecto, `kill -9` envía SIGKILL).  
-).  
- **Gestión de plano**: `fg` (traer a primer plano), `bg` (enviar a segundo plano), `jobs` (listar trabajos).  
- **Ajuste de prioridad**: `nice` (iniciar con un valor nice) y `renice` (modificar prioridad de un proceso en ejecución).  

**Desarrollo principal**  
1. **Visualización y monitoreo**: se enseña a usar `ps` para listar procesos asociados a la terminal, `ps -e` para todos los procesos del sistema y `ps aux` para una vista completa con usuario, PID, PPID, etc.; se practica filtrar con `grep`. Asimismo, se introduce `top` como herramienta interactiva que muestra en tiempo real el consumo de CPU y memoria, permitiendo ordenar por `%MEM` (tecla **M**) o `%CPU` (tecla **P**).  
2. **Control de procesos**: mediante `kill <PID>` se envía la señal SIGTERM para terminar un proceso de forma ordenada; si no responde, se usa `kill -9 <PID>` (SIGKILL) para forzar la terminación, con precaución respecto a procesos críticos del sistema.  
3. **Modos de ejecución (foreground/background)**: se explica la diferencia entre procesos que bloquean la terminal (foreground) y aquellos que la dejan libre (background). Se practica iniciar un proceso en background con `&`, pausarlo con **Ctrl+Z**, listar trabajos con `jobs`, reanudarlo en background con `bg %n` y traerlo nuevamente a foreground con `fg %n`.  
4. **Prioridad de procesos**: se describen los comandos `nice` y `renice` para ajustar el valor nice (de –20 a 19). Se realizan ejercicios donde se inicia un proceso consumidor de CPU (`yes > /dev/null`), se observa su NI con `top` o `htop`, se disminuye su prioridad con `renice +10 -p <PID>` y, usando `sudo`, se aumenta su prioridad con `renice -5 -p <PID>`.

La actividad proporciona las herramientas fundamentales para observar, controlar y priorizar procesos en un entorno Linux Ubuntu, habilidades esenciales para garantizar la estabilidad y el rendimiento del sistema.
