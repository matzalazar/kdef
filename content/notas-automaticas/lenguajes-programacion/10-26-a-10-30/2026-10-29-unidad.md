# Unidad 10 – Guía práctica: Programación Web – Introducción al HTML y PHP

## Conceptos clave

- **XAMPP**: paquete de servidor web local (Apache, MySQL, PHP) usado como entorno de desarrollo.
- **htdocs**: directorio raíz del servidor web en XAMPP donde se colocan los archivos accesibles vía `http://localhost/`.
- **index.php**: archivo por defecto que el servidor ejecuta al acceder a un directorio sin especificar nombre de archivo.
- **PHP embebido en HTML**: uso de `<?php ... ?>` y `echo` para generar contenido dinámico del lado del servidor.
- **Variables en PHP**: prefijo `$` (ej. `$titulo`), asignación y uso en salida HTML.
- **Funciones nativas**: `rand(min, max)` para enteros aleatorios; lógica de control (`if`, `for`, `while`) para bucles y condicionales.
- **Estructuras HTML dinámicas**: generación de listas `<ul><li>...</li></ul>` y bloques repetidos según valores calculados.
- **Algoritmos clásicos**: serie de Fibonacci, cálculo de factorial, filtrado de números pares en rango.

## Desarrollo principal

La guía propone una secuencia de **ocho ejercicios progresivos** que introducen la programación web del lado del servidor con PHP sobre una base HTML. El entorno de trabajo es una carpeta `guia10/` dentro de `htdocs` de XAMPP, accedida mediante `http://localhost/guia10/`.

1. **Ejercicio 1** – Crear `index.php` con una página HTML vacía y verificar que el servidor la sirve por defecto.
2. **Ejercicio 2** – Insertar un título dinámico usando `echo` dentro de etiquetas PHP.
3. **Ejercicio 3** – Definir variable `$titulo` y usarla tanto en el `<title>` como en el cuerpo de la página.
4. **Ejercicio 4** – Generar un número aleatorio con `rand()` y emitir ese mismo número de bloques HTML (iteración controlada por variable).
5. **Ejercicio 5** – Seleccionar aleatoriamente entre dos bloques HTML distintos mediante una variable aleatoria y estructura condicional.
6. **Ejercicio 6** – Calcular e imprimir el factorial de un número aleatorio (bucle acumulativo).
7. **Ejercicio 7** – Construir una lista desordenada `<ul>` con los primeros *N* términos de la serie de Fibonacci, donde *N* es aleatorio.
8. **Ejercicio 8** – Generar dos límites aleatorios *X* e *Y* y listar en `<ul>` los números pares comprendidos entre ambos.

Cada ejercicio refuerza la alternancia entre código PHP (lógica, variables, bucles) y marcado HTML (estructura, presentación), patrón base de las aplicaciones web tradicionales.
