# Guía Práctica 5: Funciones y Modularización  

**Conceptos clave**  
- **Función**: bloque de código que realiza una tarea específica y puede devolver un valor mediante `return`.  
- **Procedimiento**: función que no devuelve valor (se usa solo para efectos secundarios, como `printf`).  
- **Parámetros por valor vs. por referencia**: paso de argumentos mediante copia o mediante punteros (`&` y `*`).  
- **Recursividad**: función que se llama a sí misma para resolver un caso reducido del mismo problema.  
- **Generación de números aleatorios**: uso de `rand()` para obtener valores pseudoaleatorios entre 0 y `RAND_MAX`; limitación con el operador módulo `%` y inicialización con `srand(time(NULL))` para variar la secuencia.

   - Función que devuelve el mayor de dos números.  
   - Procedimiento que clasifica un número como positivo, negativo o nulo.

2. **Problemas avanzados** (6‑20):
