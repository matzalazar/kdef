# Unidad 01 – Introducción a la programación y diagramas de flujo

**Resumen breve**  
Esta unidad, parte de la Licenciatura en Ciberdefensa de la UNDEF, presenta los fundamentos de la programación y la elaboración de diagramas de flujo. Se describen los conceptos de algoritmo, lenguajes de programación y estilos de programación, además de detallar el proceso de desarrollo de software y las buenas prácticas para diagramar procesos.

## Conceptos y términos clave

| Término | Definición breve (según el documento) |
|---------|---------------------------------------|
| **Programa** | Conjunto de instrucciones que indica a una computadora cómo realizar una tarea específica. |
| **Algoritmo** | Secuencia finita, precisa y ordenada de pasos para resolver un problema. |
| **Lenguaje de programación** | Herramienta formal para escribir algoritmos que la máquina pueda interpretar. |
| **Lenguaje máquina** | Instrucciones binarias (0 y 1) específicas de cada procesador. |
| **Lenguaje de bajo nivel (ensamblador)** | Usa mnemónicos (ej. MOV, ADD) y depende del hardware. |
| **Lenguaje de medio nivel** | Combina características de alto nivel y cercanía al hardware (ej. C). |
| **Lenguaje de alto nivel** | Sintaxis cercana al lenguaje humano y independiente del hardware (ej. Python, Java). |
| **Compilado** | Programa traducido completamente a lenguaje máquina antes de ejecutarse. |
| **Interpretado** | Programa traducido línea por línea durante la ejecución. |
| **Estilo de programación** | Forma de estructurar y organizar el código (lineal, estructurada, modular, orientada a objetos). |
| **Diagrama de flujo** | Representación gráfica de un algoritmo con símbolos estándar y flechas que indican el flujo de ejecución. |
| **Símbolos de diagrama de flujo** | Flecha, Inicio/Fin, Proceso, Decisión, Entrada/Salida, Documento, Base de datos, Comentario. |
| **Buenas prácticas** | Reglas para diseñar diagramas claros y eficientes (un solo inicio/fin, decisiones con dos salidas, nombres descriptivos, flujo de arriba a abajo, evitar cruces de flechas, declarar variables antes de usarlas). |
