# Guía práctica Nº 1 – Diagramas de flujo  
**Licenciatura en Ciberdefensa – Lenguajes de Programación 2026**  

## Descripción breve  
Esta guía práctica introduce a los estudiantes a la creación de diagramas de flujo para resolver problemas de programación. Se presentan instrucciones generales, una lista de 15 ejercicios y ejemplos resueltos de algunos de ellos, con explicaciones paso a paso y referencias a recursos de la cátedra.

## Conceptos y términos clave  
| Término | Definición breve (según el documento) |
|---------|---------------------------------------|
| **Diagrama de flujo** | Representación gráfica de un algoritmo usando símbolos estándar (inicio, proceso, decisión, entrada/salida, fin). |
| **Variable** | Espacio en memoria reservado para almacenar datos; se declara antes de su uso. |
| **Entrada de datos** | Operación que solicita al usuario valores a través de un paralelogramo. |
| **Salida de datos** | Operación que muestra resultados al usuario mediante un paralelogramo. |
| **Decisión** | Nodo que evalúa una condición y dirige el flujo según el resultado (sí/no). |
| **Constante** | Valor fijo que no cambia durante la ejecución (ej. PI = 3.1416). |
| **Operador aritmético** | Símbolo que indica una operación ( +, -, *, / ). |

## Desarrollo principal  
1. **Instrucciones generales**  
   - Se debe usar el manual de referencia de diagramas de flujo de la cátedra.

2. **Ejercicios propuestos** (15 en total)  
   1. Sumar dos números.  
   2. Calcular el promedio de tres números.  
   3. Calcular área y perímetro de una circunferencia.  
   4. Determinar si un número es par o impar.  
   5. Comparar dos valores y mostrar el mayor.  
   6. Comparar tres números y mostrar el mayor.  
   7. Calcular la diferencia de dos números (con decimales).  
   8. Calcular área de un triángulo.  
   9. Calcular promedio de dos notas.  
   10. Convertir Celsius a Fahrenheit.  
   11. Convertir kilómetros a metros y centímetros.  
   12. Convertir kilogramos a libras.  
   13. Realizar una operación aritmética dada por el usuario.  
   14. Verificar si tres lados forman un triángulo válido.  
   15. Determinar si un número es positivo, negativo o cero.  

3. **Ejercicios resueltos**  
   - **Ejercicio 1**: Se muestra el flujo completo desde la declaración de variables hasta la suma y salida.  
   - **Ejercicio 3**: Se detalla la asignación de PI, entrada del radio, cálculo del área ($\pi r^2$) y perímetro ($2\pi r$).  
   - **Ejercicio 5**: Se explica la decisión basada en la comparación $x>y$ y los casos de igualdad o mayor.  
   - **Ejercicio 10**: Se presenta la fórmula de conversión $F = (C \times 1.8) + 32$ y la asignación a variables reales.  

4. **Formato de los diagramas**  
   - Símbolo de inicio (óvalo con “Begin”).  
   - Símbolos de proceso (rectángulos).  
   - Símbolos de decisión (rombos).  
   - Símbolos de entrada/salida (paralelogramos).  
   - Símbolo de fin (óvalo con “End”).
