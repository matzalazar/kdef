### Conceptos clave  
- **Lenguaje C**: lenguaje compilado, tipado estático, creado en 1972 por Dennis Ritchie; base de sistemas operativos y muchos lenguajes modernos.  
- **Variable**: nombre asociado a un tipo de dato en tiempo de compilación; su tipo no puede cambiar tras la declaración.  
- **Tipos de datos primitivos**: `char`, `int`, `long`, `float`, `double` (con rangos y tamaños indicados en el documento).  
- **Enteros sin signo (`unsigned`)**: rango que comienza en 0 y duplica el rango positivo (ej. `unsigned char` 0‑255).  
- **Overflow (desbordamiento)**: comportamiento de aritmética modular cuando se supera el límite del tipo (ej. 255 + 10 → 9 en `unsigned char`).  
- **Constantes**: declaradas con `const` (tipo respetado) o `#define` (sustitución textual sin tipo).  
- **Comentarios**: `//` (una línea) y `/* … */` (varias líneas); usados para documentación y desactivación temporal de código.  
- **Operadores**: aritméticos (`+ - * / %`), unarios (`++ --`), de comparación (`== != > < >= <=`), lógicos (`! && ||`), de asignación compuesta (`+= -= *= /= %=`).  
- **Precedencia y asociatividad**: orden de evaluación definido (asignación < suma/resta < multiplicación/división < unarios); asociatividad mayormente izquierda‑a‑derecha, excepto unarios y asignación (derecha‑a‑izquierda).  
- **Estructuras de control**: `if/else`, `switch` (con `case`, `break`, `default`).  
- **Bucles**: `for` (inicialización, condición, incremento), `while` (0‑n ejecuciones), `do while` (1‑n ejecuciones); `break` para salida inmediata.  
- **Punteros**: variable que almacena una dirección de memoria; operadores `&` (referencia) y `*` (desreferencia); `%p` para imprimir direcciones.  
- **Arreglos**: colección contigua de elementos del mismo tipo; indexados desde 0; nombre del arreglo equivale a puntero al primer elemento; sin verificación de límites en tiempo de ejecución (comportamiento indefíndo si se accede fuera de rango).  
- **Recorrido**: bucles `for` para vectores; bucles anidados para matrices.  
- **Búsqueda lineal**: revisión secuencial de elementos hasta encontrar el valor buscado; uso de bandera (`-1` para no encontrado).  
- **Ordenamiento burbuja (Bubble Sort)**: algoritmo que compara elementos adyacentes y los intercambia si están en orden incorrecto; después de cada pasada el mayor elemento “burbujea” al final.
