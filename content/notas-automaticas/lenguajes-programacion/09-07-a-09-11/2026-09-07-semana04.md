**Conceptos clave**  
- **Puntero**: variable que almacena una dirección de memoria; se declara con `tipo *nombre;` y se manipula con los operadores `&` (referencia) y `*` (desreferencia).  
- **Vector/arreglo unidimensional**: bloque contiguo de casilleros de memoria, índice desde 0 a *n‑1* (ej. `int v[10];`).  
- **Matriz/arreglo bidimensional**: arreglo de arreglos (ej. `int m[3][5];`).  
- **Recorrido con `for`**: estructura iterativa para acceder secuencialmente a los elementos de un vector o matriz.  
- **Búsqueda lineal**: recorre el vector elemento a elemento hasta encontrar el valor buscado; no requiere orden previo.  
- **Ordenamiento burbuja (Bubble Sort)**: compara pares adyacentes y los intercambia si están fuera de orden; cada pasada lleva el mayor elemento al final.  
- **Memoria RAM**: tabla de casilleros con dirección y contenido; se divide en secciones de código, datos, pila y heap durante la ejecución de un programa.  
- **OnlineGDB**: IDE en la nube para escribir, compilar y ejecutar código C/C++ con un solo clic (https://www.onlinegdb.com/).
