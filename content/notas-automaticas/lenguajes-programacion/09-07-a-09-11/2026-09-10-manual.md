# Manual de referencia de C v1.1

## Conceptos clave

- **Lenguaje C**: lenguaje compilado, tipado estático, creado en 1972 por Dennis Ritchie.
- **Variables**: deben declararse con tipo; reglas de nombres (letras, dígitos, guión bajo, no iniciar con número).
- **Tipos de datos**: char (1 byte), int (2 o 4 bytes según arquitectura), long (4 bytes), float (4 bytes), double (8 bytes); rangos y precisión.
- **unsigned**: modifica tipos enteros para que el rango empiece en 0 y duplique el positivo.
- **Overflow (desbordamiento)**: ocurre al superar el rango; en tipos unsigned se envuelve mediante aritmética modular.
- **Constantes**: se declaran con `const` (tipo respetado) o con `#define` (sustitución textual sin tipo).
- **Comentarios**: `//` para una línea; `/* … */` para varias líneas.
- **Operadores**: aritméticos (`+ - * / %`), unarios (`++ --`), de comparación (`== != > < >= <=`), lógicos (`! && ||`), de asignación compuesta (`+= -= *= /= %=`).
- **Precedencia y asociatividad**: orden de evaluación; asignación derecha‑a‑izquierda, unarios derecha‑a‑izquierda, resto izquierda‑a‑derecha.
- **Estructuras de control**: `if/else`, `switch` con `break` y `default`.
- **Bucles**: `for` (inicialización, condición, incremento), `while` (condición al inicio), `do while` (ejecuta al menos una vez); `break` para salir inmediatamente.
- **Punteros**: variable que almacena dirección de memoria; `&` (referencia) obtiene dirección; `*` (desreferencia) accede al valor.
- **Arreglos**: colección contigua de mismos tipos; indexados desde 0; nombre del arreglo equivale a puntero al primer elemento.
- **Recorrido**: con bucles `for`; advertencia de no verificar límites → comportamiento indefinido si se sale del rango.
- **Búsqueda lineal**: revisar elemento a elemento hasta encontrar el valor.
- **Ordenamiento (Bubble Sort)**: compara adyacentes y los intercambia; cada pasada lleva el mayor al final.
- **Funciones y procedimientos**: función devuelve valor con `return`; procedimiento declarado `void`; `void` también indica ausencia de valor y punteros genéricos.
- **Variables locales y globales**: locales dentro de función; globales fuera de `main`, visibles en todo el programa (uso con cuidado).
- **Paso de parámetros**: por valor (copia) y por referencia (puntero, permite modificar original).
- **Funciones recursivas**: función que se llama a sí misma; necesario condición de corte.
- **Buenas prácticas**: usar nombres descriptivos, evitar variables globales innecesarias, comentar el porqué, controlar límites de arreglos, usar `void` para claridad, etc.
