**Conceptos clave**  
- **Constante**: valor fijo definido antes de `inicio` (ej. `definir PI 3.14`).  
- **Variable**: necesita tipo básico (entero, real, booleano, carácter, cadena) y se declara con `definir <nombre> como <tipo>;`.  
- **Ingreso de datos**: `ingresar (A);` o `ingresar (A, B);`.  
- **Salida de datos**: `imprimir (A);` o con texto fijo `imprimir ("Texto");`.  
- **Asignación**: `S = A + B;` (uso de `=`).  
- **Operaciones básicas**: `+`, `-`, `*`, `/`, `%` (módulo).  
- **Estructuras condicionales**: `si (condición) { … }`, `si … sino { … }`, `según (variable) { caso …: … salir; }`.  
- **Bucles**: `para (i = 0; i < 10; i++) { … }` (for), `mientras (condición) { … }` (while), `hacer { … } mientras (condición);` (do‑while).  
- **Estilo recomendado**: palabras clave en minúsculas, uso de llaves `{}` para delimitar bloques, indentación para legibilidad.
