# Semana 02 - Guía práctica: Pseudocódigo

## Conceptos clave
- Pseudocódigo (el documento no brinda una definición formal)
- Ciclo **for** y ciclo **while**
- Promedio de un conjunto de números
- Número primo
- Serie de Fibonacci
- Factorial de un número
- Operadores aritméticos (+, -, *, /)
- Conversiones de unidades (Celsius‑Fahrenheit, km‑m‑cm, kg‑libras)
- Condicionales (par/impar, mayor/menor, positivo/negativo/cero)
- Validación de triángulo a partir de sus lados

## Desarrollo principal
La guía contiene veinte ejercicios de pseudocódigo. Los primeros quince son problemas básicos que implican leer uno o varios valores y realizar operaciones simples: suma, promedio, área y perímetro de una circunferencia, detección de par/impar, comparación de números, diferencia absoluta, conversiones de temperatura y unidades, y operaciones con un operador ingresado. Los ejercicios del 16 al 20 aumentan en complejidad y requieren el uso de estructuras repetitivas: calcular el promedio de *N* números, determinar si un número es primo verificando divisores hasta su raíz cuadrada, generar la serie de Fibonacci hasta un límite *N*, mostrar la tabla de multiplicar de un número del 1 al 10 y calcular el factorial de un número ingresado. Se indica utilizar el manual de referencia de pseudocódigo de la cátedra y se sugieren editores como Notepad++, Phoenix Code o VS Code Web para la edición.

## Conclusiones
Esta guía práctica consolida la capacidad de traducir diagramas de flujo a pseudocódigo, reforzando el uso de estructuras secuenciales, condicionales y de repetición. Al resolver estos ejercicios los estudiantes afianzan la lógica de programación y se preparan para la implementación en lenguajes de programación concretos.
